# Notified – Associate Web Developer Technical Assessment

**Prepared by:** Robert Quintero
**Position:** Associate Web Developer

## 1. Project Overview

The objective of this assessment was to recreate the provided corporate investor relations website mockup using HTML and CSS, with a focus on visual accuracy and responsive design.

Although the assessment required only one implementation, I decided to develop two separate versions using **Drupal and Next.js**. This allowed me to demonstrate my familiarity with the CMS technology mentioned in the job description while also showcasing my current frontend development workflow.

Both implementations follow the supplied desktop reference and include responsive layouts for smaller screens.

## 2. Implementation Approach

I used the one-week assessment period as an opportunity to explore two different approaches to implementing the same design.

**A. Drupal Implementation**

Since Drupal is specifically mentioned in the job description, I wanted to demonstrate my ability to work within a CMS environment and translate a provided design into a Drupal-based website.

I initially used Tailwind CSS for styling but encountered limitations with certain utilities in the existing setup. To address this, I supplemented the implementation with standard CSS where necessary to achieve the intended layout and appearance.

**B. Next.js Implementation**

I also developed a separate version using Next.js, which is the framework I currently use for my personal and freelance development projects.

I used Tailwind CSS for styling and relied primarily on native Next.js functionality. I intentionally avoided additional UI component libraries and unnecessary third-party dependencies to keep the application lightweight and maintainable.

## 3. Design Process and Responsive Design

I started by reviewing the supplied desktop mockup, identifying its main sections, layout structure, typography, colors, spacing, and visual elements.

During the review, I noticed some inconsistencies in spacing, padding, typography, and text alignment across certain sections. I considered these observations during implementation while prioritizing consistency with the provided reference.

Since the assessment only included a desktop mockup, I also created an additional **mobile design in Figma** before proceeding with the responsive implementation.

This provided a visual reference for adapting the sections, spacing, and content arrangement to smaller screens rather than simply scaling down the desktop layout.

Both implementations were subsequently adjusted and tested across different screen sizes.

## 4. Technical Implementation

The two versions used different development approaches:

- **Next.js:** Used Next.js and Tailwind CSS to build the frontend, manage the application structure, and implement responsive layouts.
- **Drupal:** Integrated the design within a Drupal environment, using Tailwind CSS supplemented with standard CSS where necessary.

For both implementations, I focused on maintaining a straightforward code structure, consistent styling, and responsive behavior.
